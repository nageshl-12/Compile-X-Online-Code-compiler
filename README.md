# Compile-X-Online-Code-compiler
CompileX - Online Code Compiler supporting Java, JavaScript, Python, C, C++, C#, and HTML/CSS/JS with real-time execution.



# CompileX 💻

🌐 **Live Demo:** https://compilex.co.in/

---

## 🚀 About

**CompileX** is a modern online code compiler that allows users to write, compile, and execute code directly in the browser. It supports multiple programming languages and provides real-time output without requiring any local setup.

---

## ✨ Features

* ⚡ Real-time code execution
* 🌍 Multi-language support
* 🧠 Interactive input/output handling
* 🎯 Clean and responsive UI
* 🔒 Basic security for safe execution
* 🚀 Fast performance using WebSockets

---

## 🧠 Supported Languages

* C
* C++
* Java
* Python
* JavaScript
* C#

## ⚙️ Installation

1. Clone the repository:

```bash id="j2vhxf"
git clone https://github.com/nageshl-12/Compile-X-Online-Code-compiler.git
```

2. Go to project folder:

```bash id="l8j7q0"
cd Compile-X-Online-Code-compiler
```

3. Install dependencies:

```bash id="6zvnrs"
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash id="9qg7l4"
cd server
npm start
```

### Start Frontend

```bash id="g8l9sf"
cd client
npm run dev
```

---

## 🔐 Notes

* `node_modules` is not included in this repo
* Run `npm install` before starting
* Make sure backend server is running before frontend
